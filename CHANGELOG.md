All the packages in `packages/` share one version.

### Runtime (#47)

The runtime keeps only node kinds; combinators built from them moved to the foreign modules of `Screamer.Signal` and `Screamer.Event`. `Screamer.Runtime.Unsafe` is the JavaScript API for add-on FFI.

### Context, Host and Pending (#48)

- New: `Screamer.Context` (`key`, `provide`, `ask`, `uniqueId`), `Screamer.Host` (`Host`, `browserHost`, `host`, `withHost`), `Screamer.Pending` (`pending`, `settled`).
- `Screamer.Time` uses the scope's host instead of global timers.
- `Resource.retry :: RetryPolicy -> (a -> Aff b) -> Owned (a -> Aff b)` (was `-> a -> Aff b`); its waits use the host.
- `resource`, `resourceWith` and `request` register each running request with `Pending`.

### Renderer backend and SSR seams (#33, #34 to #37)

Server rendering will live in a separate library; the core gains the seams it needs (see `docs/ssr.md`).

- New: `Screamer.Renderer` (`Backend`, `browserBackend`, `createBrowserBackend`, `rendererKey`, `interactive`, `delegated`). Every node operation in `Screamer.Element` goes through the backend in context; event delegation moved into the browser backend.
- New: `Screamer.Element.Unsafe.instantiateWith`; `mount` is built the same way.
- New: `foreignWithFallback_`. When the backend is not interactive, `on_` attaches nothing and `foreign_` runs no setup.
- `Screamer.Router`: `RouterEnv`, `browserRouter`, `staticRouter`, `routerKey`, `withRouter`, `router`. `navigate` and `redirect` are now `String -> Owned Unit` (were `String -> Effect Unit`); from an event handler, use `push`/`replace` of `router`, or `browserRouter.push`.
- New: `Screamer.Html.Reflect`, the HTML form of each DOM property, generated by `npm run codegen:dom`.

### Framework primitives (#50)

- New in `Screamer.Element`: `portal`, `catchError`, `suspense` (also in the `Screamer` prelude) and `withLeave`.
- New: `Screamer.Source.focus` and `prop`. `Screamer.Form`'s `Context` is now `{ props, state :: SignalSource i, reveal }` (was `value` and `modify`), built with them.
- New: `Screamer.Renderer.boundaryKey`, which `suspense` reports its boundaries to.
- Development builds warn once per node when a paused stateful signal is read, naming the operator. A write inside a derivation was already an error in development builds and stays one.
